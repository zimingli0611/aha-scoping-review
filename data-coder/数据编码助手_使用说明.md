# 数据编码助手 · 使用说明

全文筛选做完，手里是一份纳入的文献清单。下一步是数据提取：按一张编码表，把每篇论文里和研究问题有关的信息一项项记下来。这个小工具帮你做完这一整段：**设计编码表 → 四个检查 → 随机抽一批试编 → 改编码表、定版 → 编完全部 → 导出图、表 3.1、附录编码表和 3.4 的段落**。

配套视频：栗子悟了《你人生中的第一篇综述》第 9 期。前两步用的是第 7 期的“摘要筛选助手”和第 8 期的“全文筛选助手”。

下载：在 GitHub 上搜 **aha-scoping-review**，打开这个仓库就能下载工具和这份说明。

> English quick guide: see the end of this file.

## 一、打开

- 整个工具就是一个文件：`data-coder.html`。双击，用浏览器打开就行，推荐 Chrome 或 Edge，不用安装。
- 工具不联网，文献、PDF、编码表和编好的数据都只存在你自己的浏览器里。关掉页面再打开，会回到上次的地方。

## 二、导入纳入的文献（开始页第 1 步）

两种导入方式，任选一种：

1. **推荐**：把全文筛选用的那几个 bib 文件，和全文筛选助手导出的**进度备份**（`全文筛选进度备份.json`）一起拖进来。
   - 工具按全文阶段的判断，自动挑出最终纳入的文献。两个人筛选的，按统一后的结果算。
   - 全文阶段写的备注也会带过来，编码时显示在每篇的标题下面。
2. 只导入全文筛选导出的 `纳入的文献.bib`。这样 bib 里的每一条都当作纳入的文献。

> bib 文件要和全文筛选用的是同一批：工具按“文件名 + 引用键”对上全文阶段的判断，对不上会提醒你。

## 三、导入全文 PDF（开始页第 2 步）

- 把 PDF 或整个文件夹拖进来，或者点“选择 PDF”“选择文件夹”。也可以在 **⚙ 设置 → 文献和 PDF** 里继续添加。
- 文件名里有引用键（比如 `sim-acm-015.pdf`）、DOI，或者大部分题目里的词，就能自动对上。第 8 期已经按引用键改好名的，直接拖进来就行。
- 对不上的 PDF，编到对应的那篇时，在“从没对上的 PDF 里选…”里指定。

## 四、编码表（开始页第 3 步，和顶部的“编码表”页）

**分块**：基本信息一块，每个研究问题一块。三个研究问题，就是四块。每块一个颜色，导出的表 3.1 也用这个颜色。

**每一项写清楚**：

| 要写的 | 说明 |
| --- | --- |
| 填法 | ❍ 单选、❏ 多选、[...] 摘录原文、# 数字 |
| 选项 | 每个选项一行，后面一栏写这个选项是什么意思（会写进附录） |
| “其他” | 勾上以后，编码时选“其他”可以写几个字；“其他”用多了，四个检查会提醒你拆分 |
| “未报告” | 原文没写时点“未报告”。它和“没有”不一样：“没有”是原文写了没有。需要“没有”，就加一个选项 |
| 可以留空 | 比如“疑点”，大多数论文没有，空着不算没编完 |
| 编码说明 | 定义（这一项记什么）、怎么判断（拿不准时按什么规矩）、例子。换个人来编，也能编得一样 |
| 打算画什么图 | 条形图（一项单独数）、热力图（和另一项交叉）、表格、不画 |
| 从文献信息自动带入 | 年份、出处、文献类型可以从 bib 里带入，编的时候不用再填 |

- 编号 C1、C2…… 按顺序自动排。拖动左边的项，或者点 ↑ ↓，可以换位置、换块，编号跟着变。
- **示例编码表**：点“示例编码表”，可以载入视频里 AI 写作工具的例子：第一版（12 项）、第二版（试编第一批以后，13 项）、定稿（14 项）。先看看长什么样，再改成你自己的。
- **AI 起草**：点“AI 起草”，填研究主题和研究问题，复制提示词，粘贴到任何一个 AI 的对话框里。AI 回复里有一段 JSON，复制下来，点“粘贴 AI 给的编码表”贴进来。格式有问题，工具会说清楚是第几块、第几项、哪里不对。工具本身不联网，提示词里只有你填的内容。AI 给的选项和出处，要自己核对。
- **编码表文件**：两个人编时，一个人设计好，点“编码表文件 → 导出编码表（JSON）”发给对方，对方导入，两个人用的就是同一份。

## 五、四个检查

顶部点“四个检查”。每一项都过一遍：

| 检查 | 问自己 | 工具怎么帮你 |
| --- | --- | --- |
| **对得上** | 这一项回答哪个研究问题？每个研究问题要的信息表里都有吗？ | 研究问题没有对应的项、项没放进任何一块，都会标出来 |
| **找得到** | 论文里一般会写吗？ | 试编以后，算出每一项“未报告”或空着的比例；一半以上标红 |
| **答得出**（最重要） | 编完以后，这个研究问题可能得到什么答案？ | 每个研究问题一个框，写一句可能的答案；旁边是试编的真实分布，对一对 |
| **画得出**（最容易忘） | 用什么图、什么表展示？ | 没想好怎么画的项会标出来；打算画的图，用试编的数据先画一张小图 |

- 答案要有意义，比如指出一块空白、一个规律。想来想去只能写出“研究很多，各有不同”，说明这几项没选好。
- **“其他”用得太多**（超过四分之一的论文）会单独提醒，并列出大家在“其他”里写了什么。视频里评价维度 8 篇都用了“其他”，拆出了“学习效果”“掌控感与作者身份”。
- 右上角可以选按哪些文献算：全部已编的，或者只看某一批。

## 六、定版和版本记录

- **定版**：给编码表存一个版本号。建议试编之前先定一版 v1。
- 定版以后再改编码表，版本标签会变成“草稿（基于 v1 改过）”。在“版本记录”页能看到改了什么：新增、删去、改名的项，新增、删去、改名的选项，改过的编码说明。
- 再点“定版”，弹窗里列出改动，写一两句为什么改（写 3.4 时用）。下面列出**已经编过的文献里要重编的项**：新加的项，以及编的时候说明和现在不一样的项。不勾的项，保留原来编的值。
- 定版以后，这些文献会标“需要重编：C6 C8……”，只标改过的那几项。“版本记录”页右边是需要重编的清单，点“去重编”或“从第一篇开始”。改了值，或者点“看过了，不用改”，标记就消失。
- 前后用两套标准编，数字就对不上了，所以改了编码表一定要回头重编。
- 想撤回草稿里的改动，点“放弃改动，回到 vN”；也可以用某一版替换草稿。

## 七、随机抽一批，试编

- 在“编码”页左上角点 **“随机抽一批”**：填抽几篇（默认 8 篇）和随机种子，下面马上列出会抽到哪几篇。抽完看一眼：几类主要的研究都有吗？
- **随机种子**记下来，方法里可以写。在这个工具里，同样的种子、同样的文献，抽出来的一样。抽的范围是还没编、也不在试编批次里的文献。
- 抽到的标“试编第 1 批”“试编第 2 批”，没抽到的算“正式编码”。左上角的下拉框可以只看某一批。
- 视频里的做法：第一批编完 → 四个检查 → 改编码表、定版 v2 → 已编的 8 篇重编 → 再抽一批没见过的检验 → 只补了说明、没有新类别 → 定稿。

## 八、编码

界面分三栏：左边是文献列表，中间是 PDF，右边按块填。

- 单选、多选点选项；再点一下已选的单选可以取消。选“其他”会出现一个小框，写几个字。
- **未报告**：原文没写时点它（只有允许“未报告”的项才有这个按钮）。
- **证据**：记下第几页、原文怎么说。
- **疑点**：拿不准，或者论文的说法和实际做法对不上（比如摘要说提升了写作质量，实际只有自评），点“⚑ 疑点”标出来；编码表里也可以专门放一项“疑点”。
- **?**：看这一项的编码说明。勾上“显示全部编码说明”，所有项的说明都展开。
- 左边列表可以只看“还没编”“编了一半”“编完”“需要重编”“有疑点”，也可以搜索引用键、题目、摘要。
- 每改一下都会自动保存。

| 操作 | 按键 |
| --- | --- |
| 上一篇 / 下一篇（光标不在输入框里时） | ↑ / ↓，或 K / J |
| 下一篇没编完的（光标在哪儿都行） | ⌘ + Enter（Windows：Ctrl + Enter） |
| 关掉弹窗 / 离开输入框 | Esc |
| 打开使用说明 | ? |

> 点进 PDF 以后，键盘会交给 PDF 阅读器，快捷键暂时不起作用；点一下右栏的空白处就恢复了。

## 九、图表

顶部点“图表”：按编码表里每一项打算画的图，用已经编的数据画出来。条形图看哪类多、哪类少；热力图看两项的关系（比如工具类型 × 交互形式）。多选的一篇可以算进几个类别，图上会注明。每张图都能下载 SVG 或 PNG。

## 十、两人编码

课程作业、开题、PhD Qualifying Examination 这类学校里的作业和考试，一个人编码完全没问题：自己试编，自己定稿，自己编完。要投稿的话，试编的几批一般两个人各编一遍，再对一对。

1. 开始页（或 ⚙ 设置 → 编码人）选“两个人”，填上自己的编号（R1、R2 或名字缩写）。
2. 两个人导入同样的文献，用同一份编码表（一个人导出编码表 JSON，另一个人导入），各编各的。
3. 编完点右上角“两人编码” → **“导出我的编码”**，发给对方；再点 **“导入别人的编码”**。
4. 页面上逐项列出**一致率**：两人填得一样的篇数占比。单选另算 Cohen's κ；多选按每个选项“选了 / 没选”分别比，再取平均；摘录原文和数字看是否完全一样。一致率最低的几项会标出来，往往就是编码说明没写清楚的地方。
5. 右边是**对不上的格子**（哪篇 × 哪一项）。点一行，打开那篇，选“用我的”或“用 R2 的”，或者两人商量后改。导出的结果用统一后的值。
6. 下面有一句可以写进 3.4 的话，可以直接复制。

## 十一、导出

点右上角“导出”：

- **编码结果表（CSV）**：每篇一行，前面是引用键、题目、年份、出处、批次，后面每一项一列；多选用“; ”隔开；最后几列是证据、标了疑点的项、需要重编的项。Excel 可以直接打开。
- **导出表 3.1**：四块并排的编码表概览（照 Hirzle 等 2023 年那篇范围综述的 Table 2 的样子），放在 3.4 正文里。可以选中文或英文，表号可以改，下载 SVG 或 PNG。
- **导出附录编码表**：每一项的选项和填法，标出 ❍ 单选、❏ 多选、[...] 摘录原文。Markdown，或者 Word 能直接打开的 .html。
- **图**：在“图表”页逐张下载。
- **写进 3.4 的段落**：按现在的编码表、试编批次、随机种子、版本记录和编码人生成三段话（编了什么 / 编码表怎么定下来的 / 谁来编、怎么编），中文或英文。【】里的地方按你们的实际情况改；这段话只作思路参考。
- **编码表（JSON）**、**导出我的编码**（两人编码时）、**进度备份（JSON）**。

## 十二、进度保存和换电脑

- 所有东西都自动保存在当前浏览器里（IndexedDB），不会上传。
- **清理浏览器数据会把进度一起删掉。** 换电脑或清理之前，先在“导出”里下载进度备份；在新地方导入同样的文献（和 PDF），再导入这个备份（拖到开始页第 1 步，或者在“导出”窗口里点“导入进度备份”）。
- PDF 不在备份里，要重新导入。

## 十三、常见问题

- **全文筛选的进度备份对不上**：确认拖进来的 bib 文件就是全文筛选用的那几个（文件名也一样）。
- **改了编码表，编过的值还在吗**：在。工具按每一项、每个选项的内部编号记值；改名、挪位置都不影响。删掉的项不再导出，编过的值还留在进度里。粘贴 AI 的编码表、载入示例时，名字对得上的项会接着用原来的编号。
- **需要重编的太多**：定版时，只是补一句说明、不影响已经编的值的项，可以不勾。
- **PDF 显示不出来**：换 Chrome 或 Edge 试试；或者点 PDF 工具栏里的下载按钮，用别的阅读器打开。
- **界面语言**：⚙ 设置 → 语言，可以切换中文和 English。

## English quick guide

**Data Coder** (`data-coder.html`) is a single HTML file for the data-charting step of a scoping review. Double-click it to open it in Chrome or Edge. Nothing is installed or uploaded: studies, PDFs, the codebook and your coding stay in your browser. To download it, search GitHub for **aha-scoping-review**.

1. **Import the included studies**: drop in the .bib files from full-text screening with the Full-Text Screener's progress backup (JSON); the included studies are picked out and your full-text notes come along. Or import only `included-studies.bib`. Then drop in the PDFs (matched by citation key, DOI or title in the file name).
2. **Codebook**: one block for basic information, one block per research question, each with its own colour. For every item: type (❍ single choice, ❏ multiple choice, [...] copied text, # number), options with descriptions, "Other", "Not reported" (different from "none"), coding instructions (definition, how to decide, example) and the planned chart. Codes C1, C2… renumber when you drag items. Load the example codebook (version 1, version 2, final), or click **AI draft**, copy the prompt into any AI and paste its JSON back with **Paste the AI's codebook** (errors are reported by block and item).
3. **Four checks**: **Linked** (every item answers a research question), **Findable** (share of "not reported"/empty after piloting), **Answerable** (write the answer you expect for each research question next to the pilot distribution) and **Chartable** (every item has a planned chart; previews drawn from the pilot data). "Other" chosen in more than a quarter of papers is flagged for splitting.
4. **Freeze version**: freeze v1 before piloting. After edits, the **Version log** shows what changed; freezing the next version asks why and marks the changed items as **Needs recoding** in papers already coded, with a queue to work through.
5. **Draw a random batch**: choose the batch size (8 by default) and a random seed; the same seed and the same studies give the same draw, so report the seed. Batches are labelled Pilot batch 1, 2…; the rest is main coding.
6. **Coding**: papers on the left, PDF in the middle, the form on the right. Use **Not reported**, **Evidence** (page and quote) and **⚑ Doubt**. Keys: ↑/↓ or K/J move between papers, ⌘/Ctrl + Enter jumps to the next unfinished paper. Everything saves automatically.
7. **Two coders**: choose "Two" and enter your coder ID. **Export my coding**, **Import others' coding**; the tool shows per-item **Agreement** (Cohen's κ for single choice; per-option agreement averaged for multiple choice), lists the cells that differ, and lets you resolve each one.
8. **Export**: coded data (CSV, UTF-8 with BOM), **Export Table 3.1** (SVG/PNG, Chinese or English), **Export appendix codebook** (Markdown or a Word-readable .html), charts (SVG/PNG), a draft paragraph for section 3.4, the codebook JSON and a full progress backup. Clearing browser data deletes your progress, so back up often.
