# 摘要筛选助手 · 使用说明

范围综述的第一轮筛选，是对着题目和摘要，决定一条记录**排除**，还是**保留进入全文**。这个小工具帮你把这一步做快：导入检索导出的 bib 文件，一条条看，按键盘就能判断。**不用 AI 也能完整使用，默认就是不用 AI。** 想再快一点、愿意花一点钱的话，可以打开 AI 预审，让 DeepSeek 这类便宜的大模型先看一遍，给出建议、理由和摘要里的证据。也支持几个人分别筛、再一起统一结果。

配套视频：栗子悟了《从零写一篇范围综述》第 7 期。

## 一、打开

- 整个工具就是一个文件：`摘要筛选助手.html`。双击，用浏览器打开就行（Chrome、Edge、Safari、Firefox 都可以），不用安装。
- 筛选本身不联网；只有用 AI 预审时，才会连到你填的模型接口。
- 文献、判断和进度都只存在你自己的浏览器里；关掉页面再打开，会自动回到上次的地方。

## 二、准备 bib 文件

1. 在数据库里检索完，把结果导出成 BibTeX，**一定要包含摘要**。比如 IEEE Xplore 导出时选 Citation and Abstract。
2. 一个数据库导出一个文件；结果太多、要分批导出的，分成几个文件也没关系。
3. 把这些 bib 文件放进同一个文件夹，后面导入时直接选这个文件夹就行。

## 三、导入

- 在开始页把文件或整个文件夹拖进来，或者点“选择 bib 文件”“选择文件夹”。之后也可以在 **⚙ 设置 → 文献** 里再加。
- 选文件夹时，里面（包括子文件夹）所有的 `.bib` 文件都会导入，别的文件会跳过。
- **自动去重**：DOI 相同，或者“题目 + 年份”相同（不管大小写和标点），就当作同一篇，只留一条（留摘要更完整的那条）。点“看看哪些重复”可以逐条核对。
- 导入后会显示：每个文件多少条、合计多少条、去掉了多少重复、剩多少待筛。这几个数字就是流程图最上面几格。

## 四、写纳入和排除标准

- 一行一条。开头可以写编号（`IC1`、`EC1`……），不写会自动编号。
- 不知道怎么写，先点“填入示例”看看格式（示例的题目是“AI 写作工具”，换成你自己的）。
- **高亮词**（可选）：填几个支持保留的词和几个提示排除的词，摘要里出现时会画绿线或红线，扫一眼就能找到关键处。
- 筛选中途要改标准，点右上角 **⋯ → 标准**。改了标准，受影响的记录记得回头重判。

## 五、筛选

界面分三块：左边是记录列表，中间是题目和摘要，右边是你的标准（打开 AI 预审后，标准上面会多一张 AI 的卡片，标准默认收起，点一下展开）。

| 操作 | 按键 |
| --- | --- |
| 排除 | ← 或 X |
| 保留，进入全文 | → 或 K |
| 排除，并记下第 n 条排除标准 | 数字键 1–9 |
| 撤销上一次判断 | Z |
| 上一条 / 下一条（不做判断） | ↑ / ↓ |
| 标星（边界案例） | S |
| 写备注 | N |
| 打开使用说明 | ? |
| 关掉弹窗 / 离开备注 | Esc |

几条规矩：

- 第一轮只问一个问题：**它有没有可能符合？** 明确不符合的排除；符合的、看不出来的，都保留。
- 排除时顺手按数字键记下理由，后面回头检查、写方法都用得上。
- 拿不准的标个星，写一句备注，当边界案例留着讨论。
- 左边列表可以只看“未筛”“保留”“排除”“星标”的记录（打开 AI 预审后还有“和 AI 不一致”），也可以搜索。

## 六、多人筛选（投稿的论文一般要至少两个人）

投稿的论文，一般要至少两个人独立筛选；课程综述作业、开题、PhD Qualifying Examination，一个人筛也可以。

1. **开始时说清几个人**：开始页第 3 步（或 ⚙ 设置 → 审阅人）选“两个人或更多”，填上自己的编号，比如 R1、R2，或者名字缩写。
2. **各筛各的**：每个人在自己的电脑上导入同样的 bib 文件，用同一套标准，各筛一遍，不看对方的结果。文件名不一样也没关系，工具按 DOI 或“题目 + 年份”对上记录。
3. **交换结果**：筛完点右上角“多人筛选” → “导出我的结果”，得到 `筛选结果_R1.json` 这样的文件，发给对方；再点“导入合作者的结果”，导入对方的文件（几个人就导几个）。
4. **看一致性**：导入后，“多人筛选”窗口里会显示分歧多少条、一致率和 κ。两个人用 Cohen's κ；三个人以上用 Fleiss' κ，另外给出两两之间的 Cohen's κ。κ 越接近 1，判断越一致，一般 0.6 以上算比较好，0.8 以上算很好。还可以“导出对比表（CSV）”：每条记录一行，并排列出每个人的判断和理由。把它交给 AI，可以让 AI 帮你汇总分歧。
5. **一起统一**：点“开始统一分歧”，或者在顶部切到“统一结果”。左边“待统一”列出有分歧的记录，右边是每个人的判断、理由和备注。大家讨论后，用同样的按键定下最终结果（← 排除、→ 保留，数字键记理由）。所有人判断一样的记录，自动算作最终结果。
6. **写进论文**：“多人筛选”窗口里有一句现成的话：几个人独立筛、一致率、κ、分歧多少、怎么解决的，点“复制”就能用。导出的保留记录（.bib）和流程图数字，都按统一后的最终结果算。

## 七、AI 预审（可选，默认不用）

不用 AI 也能把筛选完整做完；导入、筛选、导出、进度保存都一样。想提速的时候再打开：

1. **拿一个 API key**：在 DeepSeek 开放平台（platform.deepseek.com）注册，充一点余额，创建一个 API key。
2. **打开并填进工具**：⚙ 设置 → **AI 预审**，选“用 AI 预审”，再填上 API key（开始页第 3 步勾上“用 AI 预审”也行）。接口地址默认是 `https://api.deepseek.com`，模型默认是 `deepseek-flash`（2026 年 10 月 DeepSeek 文档里便宜的那个模型；另一个是 `deepseek-v4-pro`）。DeepSeek 的模型名如果有变化，按它的官方文档改。工具默认关掉 DeepSeek 的“思考模式”，筛摘要用不着，更快也更省；需要的话可以在“更多”里打开。其他兼容 OpenAI 格式的服务也能用，改接口地址和模型名即可。
3. **选输出语言**：⚙ 设置 → **语言** → AI 输出语言，可以选中文、English，或者选“其他”自己填（比如 日本語、Español）。AI 的理由会用这种语言写；证据照摘要原文摘录，不翻译。
4. **开始预审**：点右上角“AI 预审”，选范围（还没预审过的 / 我还没筛的 / 全部重新预审），建议**先试一条**，看看理由和证据靠不靠谱，再点“开始预审”。中途可以暂停、停止；失败的可以一键重试。
5. **看结果**：每条记录右边多一张卡，写着 AI 的建议（建议排除 / 建议保留 / 看不出来）、依据哪条标准、一句话理由；摘要里的证据用黄色划出来，点卡片上的证据会跳到原文位置。列表上方可以按 AI 的建议筛选，比如先过一遍“建议排除”的那一批。

**花多少钱**：每条记录大约八九百 tokens。按 2026 年 10 月 deepseek-flash 的价格（高峰时段每百万 tokens 输入 2 元、输出 8 元，空闲时段半价），几百条摘要大约几毛钱到一块钱；以服务商官网价格为准。预审窗口里会显示预计用量和已用量；单价可以在 ⚙ 设置 → AI 预审 → 更多 里按官网价格改。

**会发出去什么**：你写的标准，以及每条记录的题目、关键词和摘要，会发给你填的模型服务商。API key 只存在你的浏览器里；不勾“记住密钥”的话，关掉页面就忘了。

**不想用了**：在 ⚙ 设置 → AI 预审 里选“不用 AI，自己筛”，AI 相关的按钮和卡片就都收起来；之前的预审结果会留着，再打开时还在。

**AI 只是建议**：最后的判断都由你来做，工具里也没有“一键采纳 AI 建议”的按钮。你的判断和 AI 不一样的记录，会单独列在“和 AI 不一致”里，方便复查。写论文的方法部分时，如实说明用了哪个模型、它做了什么、你怎么核对的。

## 八、导出

点右上角“导出”：

- **筛选结果表（CSV）**：每条记录一行，有你的判断、排除理由、星标、备注、AI 的建议和理由、和 AI 是否一致。Excel 可以直接打开。
- **保留的记录（.bib）**：只含保留进入全文的记录，下一步读全文时用。
- **进度备份（JSON）**：换电脑或换浏览器时用。
- **流程图数字**：导入多少、去重多少、排除多少（按理由）、保留多少，可以直接复制。
- 多人筛选时还有：**导出我的结果**（给合作者）、**对比表（CSV）**；保留的记录和流程图数字按统一后的最终结果算，流程图数字后面附上一致性的那句话。

## 九、进度保存和换电脑

- 导入的文献和进度都自动保存在当前浏览器里。关掉页面再打开，会自动恢复上次导入的文献，回到上次的地方，不用重新导入。
- 中途加了新的 bib 文件，已经做过的判断会保留。
- **清理浏览器数据会把进度一起删掉。** 换电脑、换浏览器或清理之前，先导出“进度备份”；在新地方导入同样的 bib 文件，再在“导出”窗口里导入这个备份。

## 十、常见问题

- **导入后显示 0 条**：确认文件是 BibTeX 格式（以 `@article{`、`@inproceedings{` 这样的条目开头）。
- **有的记录没有摘要**：去另一个数据库或出版社网站查一下；实在找不到，就保留到全文阶段。
- **AI 预审报错**：401 是 API key 不对或已失效；402 是账户余额不足；网络问题会自动重试几次，还不行就点“重试失败的”。
- **同时做两个综述**：不同的 bib 文件，进度是分开存的，互不影响。
- **合作者的结果有很多条对不上**：确认大家导入的是同一次检索导出的同一批 bib 文件。
- **界面语言**：⚙ 设置 → 语言，可以切换中文和 English。界面语言和 AI 输出语言是分开设置的。

## English quick guide

**Abstract Screener** is a single HTML file for the title-and-abstract screening round of a scoping review. Double-click it to open it in your browser; nothing is installed and everything stays in your browser.

1. **Import**: drop .bib files or a whole folder on the start page, or use "Choose .bib files" / "Choose a folder" (also under ⚙ Settings → Files). Every .bib file in the folder and its subfolders is imported. Duplicates (same DOI, or same title + year) are merged, keeping the copy with the fuller abstract.
2. **Criteria**: one inclusion or exclusion criterion per line, optionally starting with a code (IC1, EC1…). Optional highlight words get a green or red underline in abstracts.
3. **Screen**: ← exclude, → keep for full text, 1–9 exclude with criterion n, Z undo, ↑/↓ move, S star, N note, ? help. When unsure, keep.
4. **AI pre-screen (optional, off by default)**: everything works without AI. To use it, get an API key from the DeepSeek platform (platform.deepseek.com), choose "Use the AI pre-screen" under ⚙ Settings → AI pre-screen and enter the key (default endpoint `https://api.deepseek.com`, model `deepseek-flash`, with DeepSeek's thinking mode switched off; any OpenAI-compatible service works). Choose the AI output language under ⚙ Settings → Language (Chinese, English, or type any other language). Then click "AI pre-screen", try one record first, and start. Each record gets a suggestion, the matching criterion, a one-sentence reason and highlighted evidence. A few hundred abstracts usually cost well under a few CNY; check the provider's prices. Your criteria and each record's title, keywords and abstract are sent to the provider; the key stays in your browser. The AI only suggests; you decide.
5. **Team screening**: papers for publication usually need at least two independent reviewers (one is fine for a course review, a proposal or a PhD Qualifying Examination). Choose "Two or more" and enter your ID (R1, R2…). Each reviewer imports the same .bib files and screens alone, then exports "my results" under "Team screening" and imports the others'. The tool shows agreement (Cohen's κ for two, Fleiss' κ plus pairwise κ for more), exports a side-by-side comparison CSV you can give an AI to summarize, and lists disagreements in "Consensus" for you to resolve together. A ready-made sentence for your paper can be copied; the kept .bib and flow-diagram numbers use the final decisions.
6. **Export**: results table (CSV), kept records (.bib), progress backup (JSON), and the numbers for your PRISMA flow diagram.
7. **Saving**: imported files and progress are saved in the browser; close it and reopen to pick up where you left off. Clearing browser data deletes it, so download a progress backup first; to continue elsewhere, import the same .bib files and then the backup.
