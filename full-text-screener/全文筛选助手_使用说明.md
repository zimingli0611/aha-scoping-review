# 全文筛选助手 · 使用说明

范围综述的第二轮筛选要读全文：第一轮保留下来的每一篇（摘要筛选助手里导出的“保留进入全文”就是这一轮的清单），决定**纳入**、**排除**（记一条排除标准作为主要理由），还是**没有获取到全文**。这个小工具把记录、PDF 和判断放在同一个窗口里，读完自动画出 PRISMA 流程图。

配套视频：栗子悟了《从零写一篇范围综述》第 8 期。第一轮用的是第 7 期的“摘要筛选助手”。

> English quick guide: see the end of this file.

---

## 一、打开

- 整个工具就是一个文件：`全文筛选助手.html`。双击，用浏览器打开就行，推荐 Chrome 或 Edge，不用安装。
- 工具不联网，记录、PDF、判断和进度都只存在你自己的浏览器里。关掉页面再打开，会回到上次的地方。

## 二、导入要读全文的记录（开始页第 1 步）

两种导入方式，任选一种：

1. **推荐**：把第一轮用的那几个 bib 文件，和摘要筛选助手导出的**进度备份**（`筛选进度备份.json`）一起拖进来。
   - 工具会按第一轮的判断，自动挑出保留下来的记录。
   - 流程图前半段的数字也会自动填好：各个库检索到多少、重复多少、第一轮排除多少，以及每条理由的篇数。
   - 第一轮的标准、备注和星标也会一起带过来。
   - 多人筛选时，第一轮按统一后的最终结果算。
2. 只导入第一轮导出的 `保留进入全文.bib`。这样所有记录都算要读全文的；流程图前半段的数字，要对照摘要筛选助手“导出”里的流程图数字手动填。

> bib 文件要和第一轮用的是同一批：工具按“文件名 + 引用键”对上第一轮的判断，对不上会提醒你。

## 三、导入全文 PDF（开始页第 2 步）

- 把 PDF 或整个文件夹拖进来，或者点“选择 PDF”“选择文件夹”。也可以在 **⚙ 设置 → 记录和 PDF** 里继续添加。
- **自动对上**：文件名里有引用键（比如 `sim-acm-078.pdf`）、DOI，或者大部分题目里的词，就能自动对上对应的记录。
- **命名标准：统一用引用键**，也就是 bib 里每条记录 `@inproceedings{` 后面的那个编号，例如 `sim-acm-078.pdf`。这个工具、下一步的编码表都按引用键对记录，文件名和它一致，后面就不用再对。
- **整理可以交给 AI**：把保留的 bib 和 PDF 文件夹一起给 AI（能直接操作文件夹的，比如 Claude Code、Codex，可以直接改好），让它：
  1. 按引用键给每个 PDF 改名；
  2. 打开每个 PDF 核对题目和作者，和记录对不上的（下错了文章、拿到的是别的版本）列出来；
  3. 对照清单，列出还缺哪几篇。
  改名之前先留一份原文件，改完抽几个看看对不对。
- **对不上的 PDF** 会列在“没对上的 PDF”里。读到对应的那篇时，在“从没对上的 PDF 里选…”里指定就行；也可以直接点“选择这篇的 PDF”。
- 放错了，点右边的“换一个 PDF”。

**找全文的顺序**：学校图书馆 → 出版社网站 → Google Scholar → 作者主页、ResearchGate → 发邮件问通讯作者 → 馆际互借。实在拿不到的，别算成排除，记成“没有获取到全文”（见下面第五节）。

## 四、确认标准（开始页第 3 步）

- 从第一轮的进度备份里带过来，可以修改。
- **排除理由只从排除标准（EC）里选**，数字键 1–9 对应 EC1–EC9。纳入标准里写了、但排除标准里没有对应的情况（比如纳入标准要求英文全文，读全文才发现正文不是英文），就补一条 EC，加在最后，方法里写明是第二轮加的；真实论文第二轮加的 E9 也是这样。

## 五、读全文、做判断

界面分三栏：左边是记录列表，中间是 PDF，右边是这篇的信息、标准和按钮。

| 操作 | 按键 |
| --- | --- |
| 纳入 | → 或 I |
| 排除（会提醒你选理由） | ← 或 X |
| 排除，并记下第 n 条排除标准 | 数字键 1–9（EC1–EC9） |
| 没有获取到全文 | G |
| 撤销上一次判断 | Z |
| 上一篇 / 下一篇 | ↑ / ↓ |
| 标星（拿不准、边界案例） | S |
| 写备注 | N |
| 打开使用说明 | ? |

> 点进 PDF 以后，键盘会交给 PDF 阅读器，快捷键暂时不起作用；点一下右栏的空白处就恢复了。

几条规矩：

- **先读方法**：谁参与了、用的什么工具、做了什么评估；再扫一眼结果，对着标准一条条判。不用从头读到尾。
- **排除只记一个主要理由，而且一定是一条 EC**：几条都沾边时，记最直接说明它为什么排除的那一条；记法事先和合作者约定好，前后一致。流程图按理由报篇数，所以排除了却没选理由的，会列在“缺理由”里。
- **证据在哪**：第几页、哪一节，顺手写进备注。
- **没有获取到全文**：按 G，点几下下面的快捷词（图书馆没订、出版社页面打不开、联系作者没有回复、馆际互借没成功），或者自己写清楚找过哪些地方。它在流程图里单独一格，不算排除。
- 左边列表可以只看“未判断”“纳入”“排除”“没拿到全文”“缺 PDF”“星标”“缺理由”的记录，也可以搜索题目、摘要和备注。

## 六、PRISMA 流程图

点右上角“流程图”：

- 按 PRISMA 2020 的模板画：识别、筛选、纳入三段；左列是留下来的，右列是每一步去掉的。数字按你的筛选记录自动填好。
- **核对**：右边逐层检查“上一格 − 右边那格 = 下一格”，以及“全文排除的理由加起来 = 全文排除”。全部打勾才算对上；还有没判断完的，会提示还剩几篇。
- **语言**：流程图可以单独选中文或 English，和界面语言无关（比如中文界面、英文论文）。
- **第一轮的理由**：勾上“列出第一轮每条排除理由的篇数”，第一轮那格会列出每条理由的篇数。可列可不列；全文这一轮的理由一定会列出来。
- **全文都拿到了**：没拿到的是 0 篇时，默认省掉“没有获取到全文”这一格，筛选的记录直接接到读全文那格。想留着这一格（比如写一句“全部获取到了”），取消勾选“全文都拿到了时，省掉……这一格”。
- **改数字和文字**：数据库名称、每一格的数字都能手动改，改过的会标黄。手动改的数字，要能在你的记录里找到出处。“恢复自动数字”可以撤回所有改动。
- **下载**：PNG（高清，适合 Word）和 SVG（矢量，适合 LaTeX 或继续编辑）；“复制数字”会把每一格的文字复制下来。
- **写进 3.3 的句子**：全文阶段的结果（没拿到几篇、排除多少、各是什么理由、纳入多少），可以直接复制；多人筛选时还附上一致性的那句话。图号默认是 3.1，可以改。

## 七、多人筛选

投稿的论文，全文也要两个人独立读；课程综述作业、开题、PhD Qualifying Examination，一个人读也可以。

1. 开始页第 4 步（或 ⚙ 设置 → 审阅人）选“两个人或更多”，填上自己的编号（R1、R2 或名字缩写）。
2. 每个人导入同样的记录和 PDF，各读一遍，不看对方的结果。
3. 读完点“多人筛选” → “导出我的结果”，发给对方；再“导入合作者的结果”。
4. 窗口里会显示一致率和 κ（两个人用 Cohen's κ，三个人以上用 Fleiss' κ），以及分歧篇数和分歧的组合（比如 R1 排除、R2 纳入）。纳入、排除、没拿到全文三种判断都算在内。
5. 点“开始统一分歧”，或者在顶部切到“统一结果”，一起逐篇定下来。流程图、导出的结果都按统一后的最终结果算。
6. “一致性（可以写进论文）”那段可以直接复制。

## 八、导出

点右上角“导出”：

- **全文筛选结果表（CSV）**：每篇一行，有判断、理由代码、理由说明、备注、星标、PDF 文件名。Excel 可以直接打开。
- **纳入的文献（.bib）**：只含最终纳入的文献，下一步提取数据、编码时用。
- **进度备份（JSON）**：换电脑或换浏览器时用。PDF 不在备份里，要重新导入。
- 多人筛选时还有：**导出我的结果**（给合作者）。

## 九、进度保存和换电脑

- 记录、PDF、判断和进度都自动保存在当前浏览器里（IndexedDB）。PDF 比较大，几十篇论文可能占几百 MB，一般没问题。
- 少数浏览器打开本地文件时不能长期保存 PDF（会有提示）：关掉页面后要重新导入 PDF，判断结果不受影响。
- **清理浏览器数据会把这些一起删掉。** 换电脑或清理之前，先导出“进度备份”；在新地方导入同样的记录和 PDF，再在“导出”窗口里导入这个备份。

## 十、常见问题

- **第一轮的进度备份对不上**：确认拖进来的 bib 文件就是第一轮用的那几个（文件名也一样）。改过文件名的，改回去再导入。
- **PDF 显示不出来**：换 Chrome 或 Edge 试试；或者点 PDF 工具栏里的下载按钮，用别的阅读器打开。
- **很多 PDF 没对上**：把文件名改成带引用键的，比如 `sim-acm-078.pdf`，再导入一次（已经对上的不受影响）。
- **流程图的核对有红叉**：先看是不是还有没判断完的、排除了没选理由的；再看是不是手动改过数字。
- **界面语言**：⚙ 设置 → 语言，可以切换中文和 English。

## English quick guide

**Full-Text Screener** is a single HTML file for the full-text round of a scoping review. Double-click it to open it in Chrome or Edge. Nothing is installed or uploaded: records, PDFs and progress stay in your browser.

1. **Import records**:
   - Recommended: drop the same .bib files you used in round one together with the Abstract Screener's progress backup (JSON). The kept records are picked out, the criteria are carried over, and the top of the flow diagram (records per database, duplicates, round-one exclusions with reasons) fills itself in.
   - Or import only `kept-for-full-text.bib`.
2. **Import PDFs**: drop PDFs or a folder.
   - Files whose names contain the citation key, DOI or most of the title words are matched automatically. Name every file by its citation key (e.g. `sim-acm-078.pdf`); the coding table later uses the same key. An AI (an agent like Claude Code can work on the folder directly) can rename the files, check each PDF's title and authors against the record, and list what is still missing.
   - Assign the rest while reading ("Pick from unmatched PDFs").
3. **Read and decide**:
   - Keys: → include, ← exclude, 1–9 exclude with EC1–EC9, G full text not retrieved, Z undo, ↑/↓ move, S star, N note.
   - Read the methods first.
   - Record one main reason per excluded report, always an exclusion criterion (EC); if no EC covers the case, add one (and report that it was added in round two). Note the page of the evidence.
   - "Not retrieved" is its own box in the flow diagram. It is not an exclusion, so note where you looked.
4. **Flow diagram**:
   - Drawn in the PRISMA 2020 layout (Identification / Screening / Included) from your decisions.
   - Each level is checked ("previous − removed = next"; "reasons add up"). When no full text is missing, the "not retrieved" box is left out by default.
   - Choose Chinese or English labels.
   - Edit numbers if needed (edited fields turn yellow).
   - Download PNG or SVG, and copy a ready-made sentence for section 3.3.
5. **Team screening**:
   - Choose "Two or more" and enter your reviewer ID.
   - Export your results and import the others'.
   - The tool computes Cohen's or Fleiss' κ across include / exclude / not retrieved, lists the disagreements, and lets you resolve them in "Consensus".
6. **Export**: results table (CSV), included studies (.bib), progress backup (JSON; PDFs are not included).
